This paper is an AI-for-Security systems study that uses an LLM (DeepSeek-V4.1-Flash, version 1017) as one bounded component inside a human-designed compiler testing pipeline. Our work is human-driven research: the authors designed the problem formulation, system architecture, Check IR primitives, target ISA specifications, experiments, literature review, and figures. The authors also manually verified every candidate bug and wrote all upstream reports. Generative AI was used for editorial purposes in this manuscript, and all outputs were inspected by the authors to ensure accuracy and originality.

DeFenzz uses the LLM offline to extract security invariants from segmented manuals and patches, map controlling compiler branches, and write checkers over Check IR primitives. During online fuzzing, agents generate and mutate small C and C++ test programs guided by compile-time branch traces and checker verdicts. We use an LLM here because defense rules span prose manuals and patches, and triggering silent bugs requires multi-statement programs that random mutators rarely build. Model output never serves as a bug oracle: every invariant cites official documentation or patches, and each static or dynamic checker passes offline validation gates. Compiled checkers deterministically test each compiled seed during fuzzing, and the authors manually audited all 131 candidates to confirm the 111 reported bugs.

Because hosted LLM APIs are closed-weight and non-deterministic, model generations cannot be replayed bit-for-bit across runs. All 111 discovered bugs, however, have minimal C or C++ reproducers that anyone can check deterministically with stock GCC or LLVM and zero model calls. We trained no models and used only public compiler code, public ABI manuals, and synthesized test snippets. Using a compact Flash model, one-time offline preparation (38,256 calls), sliced inputs, and a 92.4% KV-cache hit rate kept total usage to 59,671 calls. AST probe rewriting and online bug checking use zero LLM calls, finishing online fuzzing in 21,415 calls (10.16 h) on one Ryzen 7 9700X server (32 GB RAM).
